# Portafolio de Juan José Alvarez Manjarrez

Sitio personal para reclutadores: desarrollador backend junior en C# y .NET, de Barranquilla. Busco prácticas o un primer rol junior.

**Sitio:** [https://artyomalvarez.github.io](https://artyomalvarez.github.io)

## Stack del sitio

- React 19 + Vite + TypeScript
- CSS con variables y Atomic Design
- Despliegue en GitHub Pages con GitHub Actions (`dist/`)

## Cómo correrlo

```bash
npm install
npm run dev
```

Build de producción:

```bash
npm run build
npm run preview
```
